# Если что-то не работает

Все команды ниже запускаются из папки с `package.json`. Подробная установка описана в [README.md](README.md).

| Симптом | Что проверить |
| --- | --- |
| `Не задана переменная ...` или нет `.env` | Запустите `npm run setup`, заполните обязательные поля и сохраните настройки |
| Панель не открывается | Оставьте `npm run setup` работающим и откройте именно адрес из терминала; при `EADDRINUSE` завершите предыдущую копию панели или другой процесс на её порту |
| `Нет рабочего токена бота` | Выполните `npm run authorize -- bot`, подтвердив код под аккаунтом бота |
| Нет токена владельца или токен другого канала | Выполните `npm run authorize -- owner:логин_канала` и подтвердите под владельцем этого канала |
| Ошибка обновления токена / HTTP 401 | Проверьте Client ID и Client Secret того же приложения, выполните повторную авторизацию нужного аккаунта и перезапустите бота |
| `missing scope` или недостаточно прав | Запустите авторизацию нужного аккаунта ещё раз: скрипт проверяет наличие требуемых прав |
| HTTP 403 | Проверьте аккаунт владельца, права приложения, статус модератора у бота и доступность функции для канала |
| Бот в чате, но молчит | Проверьте выключатели команды и модуля, канал, права отправителя, игровые режимы и паузы |
| Изменения панели не действуют | Сохраните настройки, остановите и снова запустите бота. Если команда отмечена «Отключено в чате», выберите её канал и включите команду в панели: сохранение снимет этот запрет |
| Игры доступны только администрации | Для всех зрителей напишите `!вкл` от владельца или модератора; `GAMES_DEFAULT_MODE` применяется только при первом создании игровых настроек канала |
| Не работает опрос / прогноз / смена категории | Нужен токен владельца именно этого канала; функции также могут зависеть от статуса канала на Twitch |
| Опрос уже запущен | Сначала `!endpoll`; для прогноза используйте `!predwin` или `!predcancel` |
| Ошибка Groq или `!расклад` недоступен | Проверьте ключ, модель, квоту провайдера и переключатель `!расклад` |
| Не работает `!трек` | Проверьте профиль музыки, включение команды, каналы и [инструкцию музыки](docs/MUSIC.md) |
| Ошибка чтения игровых JSON | Сохраните копию повреждённого файла. Восстановите его из резервной копии; не удаляйте всю папку данных |

Для проверки обычного ответа используйте `!пинг` от владельца канала. Неизвестные команды и команды, отключённые настройками, не вызывают сообщение об ошибке.

Ник бота берётся из OAuth-токена. Если подтвердили код не тем аккаунтом, остановите бота, удалите **только** `tokens/bot.json`, затем выполните `npm run authorize -- bot` снова. Для неверного аккаунта владельца повторите `npm run authorize -- owner:логин_канала`: скрипт сверяет логин.

Первый канал в `TWITCH_CHANNELS` использует файл `tokens/owner.json`, последующие — `tokens/owner-<канал>.json`. Если изменили порядок каналов, повторите авторизацию владельцев. Токены обновляются автоматически во время работы, поэтому резервная копия должна сохранять их актуальную версию.

Для диагностики кода:

```sh
npm test
npm run check:public
```

Тесты не подключаются к вашему чату. Реальное соединение и доступность функций Twitch проверяются после вашей авторизации командой `npm start`.

Перед отправкой логов удалите токены, коды авторизации, ключи и персональные сообщения. Не публикуйте `.env`, `tokens/`, `private/` или игровые данные. Локальная панель предназначена для настройки с вашего компьютера или через SSH-туннель.
