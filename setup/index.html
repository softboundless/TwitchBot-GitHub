01 / ПОДКЛЮЧЕНИЕ

Аккаунт и каналы

Данные приложения Twitch и каналы, в которых будет работать бот. OAuth-авторизация выполняется отдельно после сохранения.

02 / КОМАНДЫ

Оставьте нужное

Выключенная здесь команда не сработает в чате. Настройки для отдельного канала дополняют общие ограничения.

Отключение в панели имеет приоритет над командами !вкл и !откл. Ограничения из чата видны в настройках соответствующего канала. Изменения вступят в силу после перезапуска бота.

После сохранения

  1. В папке бота выполните npm run authorize и подтвердите аккаунты Twitch.
  2. Назначьте аккаунт бота модератором в своих каналах.
  3. Запустите бота командой npm start.

На GitHub загружайте код и .env.example. Ваш .env, токены и игровые данные исключены через .gitignore.
