# Необязательная команда !трек

Без музыки достаточно выбрать **«Без !трек»** в панели, сохранить `.env` и перезапустить бота. Яндекс, Python, музыкальный HTTP-мост и домен при этом не нужны.

Чтобы включить музыку, выберите **«С !трек»**, убедитесь, что сама команда разрешена, и настройте хотя бы один источник ниже. `MUSIC_CHANNELS` ограничивает каналы команды. Если список пуст, используются все подключённые каналы. Один экземпляр бота имеет один источник музыки: во всех разрешённых каналах ответ будет одинаковым.

## Вариант 1: браузерный проигрыватель

Userscript считывает исполнителя, название и состояние проигрывания из открытой вкладки Яндекс Музыки. Python и OAuth-токен Яндекс Музыки для этого варианта не нужны.

1. Подготовьте свой HTTPS-адрес с проксированием `/api/track` на музыкальный мост бота, по умолчанию `127.0.0.1:8787`. Например, публичный адрес может иметь вид `https://music.example.com/api/track`. Это адрес **музыкального моста**, а не панели настройки на порту 8788.
2. Создайте случайный секрет, например командой `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Вставьте результат только в закрытое поле `TRACK_BRIDGE_SECRET` панели. Минимум — 32 символа.
3. Введите свой адрес в `TRACK_BRIDGE_PUBLIC_URL`. Оставьте `TRACK_BRIDGE_HOST=127.0.0.1`; внешний HTTPS обслуживает ваш reverse proxy.
4. Сохраните настройки и выполните:

```sh
npm run render:track-userscript
```

5. Откройте полученный `private/yandex-track-bridge.private.user.js` в менеджере userscript вашего браузера и установите его. Адрес и разрешённый домен подставляются из ваших настроек.
6. Запустите бота, откройте `music.yandex.ru` или `music.yandex.com`, включите трек и отправьте `!трек` в чате.

Скрипт передаёт данные, пока вкладка и браузер работают. Пауза или отсутствие свежего состояния означает, что музыка не воспроизводится. Если настроен второй источник, бот может использовать его при отсутствии актуальных данных браузера.

Сгенерированный userscript содержит секрет и исключён из Git. Если поменяли секрет или адрес, создайте файл заново и переустановите его в браузере. Сам `.template` в папке `browser/` секретов не содержит.

## Вариант 2: Яндекс Музыка через Python

Этот источник использует библиотеку `yandex-music` и Ynison. Он необязателен и зависит от доступности неофициальной интеграции с Яндекс Музыкой. Для установки нужны Python 3.12+ и Git; зависимости зафиксированы в `requirements-ynison.txt`.

Windows PowerShell:

```powershell
py -3.12 -m venv .venv-ynison
.\.venv-ynison\Scripts\python.exe -m pip install -r requirements-ynison.txt
```

Linux:

```sh
python3.12 -m venv .venv-ynison
.venv-ynison/bin/python -m pip install -r requirements-ynison.txt
```

В панели задайте `YANDEX_MUSIC_TOKEN` своего аккаунта. Актуальные способы получения токена описывает [автор используемой библиотеки](https://ym.marshal.dev/token/); сам проект и сведения о нём доступны в [репозитории yandex-music-api](https://github.com/MarshalX/yandex-music-api). Не вставляйте пароль Яндекс в `.env`.

При таком расположении окружения поле `YANDEX_MUSIC_PYTHON` можно оставить пустым: бот выберет стандартный путь автоматически. Для другой установки укажите полный путь к её исполняемому файлу Python. Запустите музыку в своём аккаунте, сохраните настройки и перезапустите бота.

## Параметры и проверка

- `TRACK_COOLDOWN_MS` — минимальная пауза между запросами `!трек` в одном канале; по умолчанию 5000 мс.
- `TRACK_BRIDGE_MAX_AGE_MS` — сколько времени браузерное состояние считается свежим.
- `FOSSABOT_TRACK_API_ENABLED` и `FOSSABOT_TRACK_CHANNELS` — необязательный резервный endpoint `/api/fossabot/track` для существующей интеграции Fossabot. Для обычной команды этого бота оставьте отключённым. Запросы endpoint проверяются через API Fossabot; простой переход в браузере не является авторизованным запросом.

Если бот отвечает «Сейчас музыка не воспроизводится», проверьте воспроизведение, актуальность браузерного состояния и выбранный аккаунт Яндекс. Если он молчит, сначала проверьте `MUSIC_ENABLED`, список каналов, выключатель самой команды и её cooldown. Ошибки сети или Python смотрите в терминале бота.

Факт запуска панели или прохождения локальных тестов не проверяет воспроизведение в вашем аккаунте: это проверяется реальной командой после настройки.
